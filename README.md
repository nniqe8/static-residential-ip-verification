## 判断一条静态住宅 IP 能不能用，看这四项

判断一条静态住宅 IP 能不能用，看四件事：ASN 归属、类型库标记、黑名单记录、DNS 与 WebRTC 泄漏。前三项决定这条 IP 在平台眼里像不像真实用户，第四项决定你的真实位置有没有从浏览器里漏出去。

先把定义说清楚。静态住宅 IP 要同时满足两个条件：ASN 归属民用宽带运营商，租期内地址固定不变，缺一个就不算。市面上绝大多数号称静态住宅 IP 的产品，本质是机房托管 ISP：服务器物理上放在机房，IP 段注册在运营商名下，你在 IPinfo 或 Scamalytics 查询时显示 ISP 或 Broadband，而不是 Hosting 或 Datacenter。这类 IP 的优势是固定、长效、性价比高，和真实民房宽带仍有距离。知道这一点，你就不会以为花几十块买到的是别人家里的那条宽带。

**第 1 步，查 ASN 归属。** 打开 `ipinfo.io/<IP>`，或者用 bgp.he.net 查这个 IP 段。运营方写 AT&T、Comcast、Verizon、中国电信、中国联通、中国移动这类民用宽带运营商，算真住宅出身。写 Amazon、Google Cloud、DigitalOcean、阿里云、腾讯云、Vultr，或者公司名里带 IDC、Hosting、Data Center，就是机房 IP。这一步是一票否决项，ASN 不是 ISP，后面三步不用做了。

**第 2 步，交叉核对类型库。** 同一个 IP 分别过 ipapi.is 或 ip-api.com 看 type 字段，过 IP2Location 看 usage type，过 Scamalytics 看 fraud score。三个库里至少两个标 residential 或 ISP，欺诈分低于 25 才算通过。要求严一点的话，欺诈分压到 20 以下。

**第 3 步，查黑名单。** AbuseIPDB 看举报次数和最近一次举报时间，Spamhaus ZEN、SpamCop 这类 DNSBL 也过一遍。有过大量滥用举报的 IP，前面两项再干净也别用。

**第 4 步，查泄漏。** 打开 browserleaks.com/webrtc 和 ipleak.net，看 WebRTC 有没有把你的真实出口 IP 暴露出去，DNS 解析走的是本地还是代理端，浏览器时区和语言跟 IP 所在地对不对得上。这一步最容易被跳过，也最容易让前面的功夫白费。

四步全过，这条 IP 可以拿去养号。缺一条，只适合做采集。这是做验真时比较通行的判法。

还有两个判断上的坑。欺诈分低不代表 IP 好，它只是风险数据库里的一个维度，还要结合 ASN、运营组织、AS Type、地理位置和实际连接表现一起看，不同数据库对同一个 IP 给出不同分类是常事。另外，固定出口只解决网络环境一致性，平台风控还看设备、浏览器、时区、支付信息和操作习惯，别把固定 IP 理解成可以绕过风控。

买之前还有三件事值得问一句。IP 是怎么来的，是服务商合法向运营商申请的段，还是通过灰色 SDK 占用真实用户设备的出口，后者来源不可追溯。价格是不是低得离谱，小红书和闲鱼上远低于市场价的静态住宅 IP，很多是多人共用一个出口的共享 IP，别人滥用你连坐。覆盖国家多不多和质量好不好是两回事，目标国家的 IP 是不是原生家宽，得自己查 ASN 才知道。

## 常见问题

### 欺诈分 0 是不是就代表这条 IP 好？

不是。欺诈分只是风险数据库里的一个维度，同一个 IP 在不同库里可能给出不同分类。判断要看 ASN 归属、运营组织、AS Type、地理位置和实际连接表现放在一起。有些服务商的高级档才给 0 分 IP，普通档拿到 20 分上下也正常。

### 666clouds 卖的是静态住宅 IP 还是 VPS？

是 VPS。你拿到的是一台有 root 权限的海外服务器，它的出口 IP 带双 ISP 或原生住宅属性。要把它变成代理，需要自己在机器上搭。这点和按条卖的代理产品不一样，买之前想清楚你要的是机器还是一条地址。

### 一个静态住宅 IP 能挂几个账号？

没有通用数字。通用安全做法是一个账号一条独立 IP，电商店铺尤其如此。社媒养号有人一条 IP 挂 3 到 5 个关联度低的账号，那是经验值，不是安全保证。挂得越多，一个号出事连累其他的概率越高。

### 拿到的 IP 位置和目标地区对不上怎么办？

先确认下单时选的就是目标地区的机房。666clouds 的地区是按机房分的，选美国就是美国机器，选英国就是英国机器，不存在选国家再随机分配的情况。拿到 IP 后用 ipinfo.io 查一下实际定位，和订单不符就开工单。官网没写提供测试 IP，能不能先看段要提工单问。

### 静态住宅 IP 会不会被封？

没有任何 IP 能保证 100% 不被封。平台风控看账号行为、支付信息、操作习惯等多维信号，IP 只是其中一层。原生住宅加独享加长期固定这三个属性能把 IP 层面的触发概率压低，压不到零。
